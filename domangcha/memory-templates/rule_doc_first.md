## Documentation policy

- DIRECT read-only/trivial work: no planning DOC requirement.
- LOOP: keep bounded task/decision/checkpoint summaries when they improve resume or validation.
- GRAPH: architecture, failure paths, completion criteria, and approval boundaries are explicit artifacts.
- Public behavior changes update relevant user documentation.
- Do not generate documents merely to satisfy ceremony.
